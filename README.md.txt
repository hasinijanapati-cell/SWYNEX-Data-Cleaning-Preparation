# SWYNEX Data Cleaning & Preparation

## Project Overview
Data cleaning and preparation of a Superstore sales dataset using Microsoft Excel.

## Tool Used
- Microsoft Excel

## Cleaning Performed
- Checked for duplicate records
- Checked for missing values
- Standardized date formatting
- Verified numerical data types
- Formatted Sales and Profit values
- Checked categorical values for consistency

## Missing Values
No missing values were identified.

## Data Quality Checks
Negative Profit values were retained because they represent legitimate business losses.

## Files
- raw_superstore.xlsx — Original dataset
- cleaned_superstore.xlsx — Cleaned dataset

## Outcome
The dataset was cleaned and prepared for further analysis.
